# thai-l2-gec

**Thai Grammatical Error Correction for L2 Learners**

Data, code, model outputs, and human-evaluation results for the paper:

> Pakawadee P. Chookwan and Attapol T. Rutherford. *Grammatical Error Correction of Thai L2-Learner Text with Self-Instruct Data Augmentation.* In Proceedings of iSAI-NLP 2026.

🚀 **Try the best-performing model** (mT5-large fine-tuned with Self-Instruct augmentation) on Hugging Face:
👉 [pakawadeep/ctfl-gec-th](https://huggingface.co/pakawadeep/ctfl-gec-th)

## Data

### CTFL-GEC

Learner writing comes from the CTFL Corpus: compositions by students in Intensive Thai courses (levels 3–9) at the Center for Thai as a Foreign Language, Chulalongkorn University, collected with informed consent and anonymized. We used 370 writing pieces. They were segmented into sentences with PyThaiNLP and corrected by native Thai annotators under a minimal-edit policy, using the UA-GEC annotation format and four error categories: Grammar, Spelling, Punctuation, and Fluency.

| File | Rows | Notes |
|---|---|---|
| `data/ctfl-gec-full-uncleaned.csv` | 4,218 | all corrected sentences |
| `data/ctfl-gec-untagged/ctfl_cleaned_train.csv` | 3,668 | |
| `data/ctfl-gec-untagged/ctfl_cleaned_dev.csv` | 202 | |
| `data/ctfl-gec-untagged/ctfl_cleaned_test.csv` | 177 | 53 sentences need no correction |

The cleaned splits keep only sentences of 3–50 words (4,047 in total).

**Columns:** `writing_id`, `sentence_id`, `text` (learner input), `expected` (correction), `annotation` (inline edits as `{error=>correction:::Type}`), `tokenize` (PyThaiNLP tokens), `word_length`, `no_edit`.

⚠️ **The split is random at the sentence level**, balanced for no-edit sentences. Sentences from the same essay can therefore appear in both training and test data; every test sentence comes from an essay that also contributes training sentences. For a stricter evaluation, re-split by `writing_id`.

### Self-Instruct synthetic data

`data/synthetic/self_instruct_pairs.csv` contains 13,090 synthetic pairs (`text` → `expected`). They were generated by prompting OpenThaiGPT-1.0.0-beta-13B-chat and Gemini-1.0-Pro with eight Instruction–Input–Output examples: six drawn from 595 seed sentences from CTFL-GEC, and two from previously generated pairs. The outputs were then filtered for format and near-duplicates. These are LLM-generated and may contain unnatural or incorrect corrections.

## Evaluation

Edits are extracted with ERRANT-style M2 alignment, without error categorization, after word segmentation with PyThaiNLP's `word_tokenize` (default `newmm` engine). Scores are P, R and F0.5 on edits, plus BLEU, GLEU and CHRF (`evaluation/results/evaluation_report.csv`). Per-category recall is in `evaluation/results/category_recall.csv`.

`evaluation/predictions/` holds one CSV per system, with outputs aligned row by row to `data/ctfl-gec-untagged/ctfl_cleaned_test.csv`; `evaluation/results/evaluation_report.csv` scores these predictions. `category_recall.csv` and the human evaluation below were computed on a larger 203-sentence evaluation set: the 177 test sentences plus 26 sentences that are in the released training split.

System names: `FT` = fine-tuned on CTFL-GEC only; `SI`, `SI-150%`, `SI-200%`, `SI-300%` = CTFL-GEC plus increasing amounts of Self-Instruct data; `RTT` = CTFL-GEC plus round-trip-translation data; `ZS` = zero-shot.

## Human evaluation

`human_eval/rankings.csv` holds 406 judgments. Each of the 203 evaluation sentences was ranked by two of four native Thai annotators, using a three-way ranking interface in [Appraise](https://github.com/AppraiseDev/Appraise). The systems were Gemini-1.0-Pro (zero-shot), mT5-base-FT and mT5-large-SI-200%. System identities were hidden, display order was randomized per sentence, and ties were allowed (rank 1 = best). `human_eval/batches.json` contains the exact items shown to annotators. Annotator IDs are pseudonymous.
